# 水印清理工具（Windows 免费版）

批量去除产品图片上**产品之外的水印**，并可把产品上的敏感标志盖上 **"your logo here" 白底条**。
纯本地运行、完全免费、无显卡要求（CPU 即可），安装包不内置模型，首次使用时按需下载。

## 功能

- **自动检测水印**：OCR 文字检测 + 产品主体识别，水印蒙版自动排除产品区域，防止误擦产品
- **手动框选修正**：在预览图上拖拽补充框选遗漏的水印，或直接指定标志位置
- **AI 去水印**：免费开源 LaMa 模型（约 200MB，首次使用下载一次），模型未下载时自动降级简易修复
- **白底条覆盖**：提供敏感 logo 模板小图，多尺度模板匹配自动找到所有相同标志并盖白底条；文字可自定义
- **批量处理**：整个文件夹的图片排队处理，导出到指定目录（文件名加 `_clean` 后缀）

## 快速开始（源码运行）

```bash
pip install -r requirements.txt
cd app
python main.py
```

首次启动会提示下载 LaMa 去水印模型（只下载一次，存于 `用户目录/.watermark_cleaner/models/`）。

## 打包成 exe

Windows 下双击 `build.bat`（或手动执行其中的 pyinstaller 命令），
产物为 `dist/WatermarkCleaner.exe`，单文件、不内置模型、体积小。

## 可选：安装 Tesseract OCR 提升文字检测准确率

不装也能用（自动降级为笔画启发式检测 + 手动框选）。安装后自动文字检测更准：

1. 下载 Windows 安装包：https://github.com/UB-Mannheim/tesseract/wiki
2. 安装时勾选中文语言包（如需识别中文水印）
3. 把安装目录（如 `C:\Program Files\Tesseract-OCR`）加入系统 PATH

## 使用流程

1. 「添加图片」批量导入
2. 勾选需要的功能：去水印 / 盖白底条
3. 若盖白底条：点「选择敏感标志模板图」，选一张只含该 logo 的小截图
4. 预览图上可拖拽框选补充区域（去水印模式下=补充水印；仅盖条模式下=指定标志位置）
5. 「开始批量处理」，选输出文件夹，等待完成

## 技术说明

| 模块 | 技术 | 说明 |
|---|---|---|
| 去水印 | LaMa (ONNX, Apache-2.0) | onnxruntime CPU 推理，有 GPU 自动加速；按水印连通区域分块处理保细节 |
| 产品保护 | 背景色距离 + GrabCut | 识别白底/纯色底上的产品主体，水印蒙版自动排除产品 |
| 文字检测 | Tesseract OCR / MSER | 定位水印文字 |
| 标志覆盖 | 多尺度模板匹配 + NMS | 白底圆角条 + 自适应字号文字 |

## 已知限制（原型版）

- 半透明/渐变水印的自动检测准确率有限，请用手动框选补充
- 复杂背景（非纯色底）上的产品主体识别可能不准，可取消勾选「保护产品主体」
- LaMa 模型下载源为 Hugging Face（含国内镜像 hf-mirror），如网络不通可手动下载
  `lama_fp32.onnx` 放到 `用户目录/.watermark_cleaner/models/` 下
